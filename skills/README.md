# Skills

A collection of reusable AI skills that reflect the workflows I use.

These skills are general and can apply to brainstorming, planning, research, writing, debugging, decision-making, and other tasks.

The goal of this repository is not to store perfect prompts, but to store workflows that improve over time through use.

Each skill starts simple, is used in real situations, and is continuously updated whenever I find:
- Better approaches
- Missing steps
- Weak assumptions
- Bugs or friction in the workflow

This repository is a place to evolve those skills into better tools over time.
